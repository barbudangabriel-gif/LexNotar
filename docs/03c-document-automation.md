## Obiectiv

Generarea automată a actelor notariale din template-uri, eliminând copy-paste manual și reducând erorile.

---

## Librărie Template-uri

### Entitate: Template

**Metadata:**
- Nume: "Vânzare-Cumpărare Imobil v2025"
- Tip act (ActType): Vânzare-Cumpărare Imobil
- Versiune: 2025.1, 2025.2, etc.
- File path: template.docx
- Status: Active / Draft / Archived
- Creat de, Creat la
- Ultima modificare

**Template-uri predefinite (MVP):**
- Vânzare-Cumpărare Imobil
- Donație
- Ipotecă
- Procură generală / specială
- Testament
- Certificat de moștenitor
- Contract de întreținere

### Format Template: DOCX cu Variabile

**Exemplu fragment template:**

```
契ACT DE VÂNZARE-CUMPĂRARE

Încheiat astăzi {DATA_SEMNARE} între:

VÂNZĂTOR: {NUME_VANZATOR}, CNP {CNP_VANZATOR}, domiciliat în {ADRESA_VANZATOR}, 
CI seria {CI_SERIE_VANZATOR} nr. {CI_NR_VANZATOR}, eliberată de {CI_ELIBERAT_VANZATOR}

și

CUMPĂRĂTOR: {NUME_CUMPARATOR}, CNP {CNP_CUMPARATOR}, domiciliat în {ADRESA_CUMPARATOR},
CI seria {CI_SERIE_CUMPARATOR} nr. {CI_NR_CUMPARATOR}

Art. 1 - Obiectul contractului
Vânzătorul transmite în proprietate cumpărătorului imobilul situat în {ADRESA_IMOBIL},
înscris în cartea funciară nr. {NR_CF}, cu numărul cadastral {NR_CADASTRAL},
în suprafață de {SUPRAFATA} mp.

Art. 2 - Prețul
Prețul convenit este de {PRET} RON ({PRET_LITERE}), plătit integral la data semnării.

{CLAUZE_SPECIALE}
```

### Variabile Suportate

**Variabile simple (text/număr):**
- `{NUME_VANZATOR}`, `{CNP_VANZATOR}`, `{ADRESA_VANZATOR}`
- `{NUME_CUMPARATOR}`, `{CNP_CUMPARATOR}`
- `{ADRESA_IMOBIL}`, `{NR_CADASTRAL}`, `{NR_CF}`, `{SUPRAFATA}`
- `{PRET}`, `{PRET_LITERE}`
- `{DATA_SEMNARE}` (format: 21 Noiembrie 2025)

**Variabile computate:**
- `{PRET_LITERE}`: Conversie automată număr → text (150000 → "o sută cincizeci de mii")
- `{DATA_CURENTA}`: Data generării actului
- `{NUME_NOTAR}`, `{SEDIU_NOTARIAT}`: Din profil notar

**Blocuri condiționale (roadmap V2):**
```
{IF CLAUZA_INALIENABILITATE}
Art. X - Clauză de inalienabilitate
Bunul nu poate fi înstrăinat timp de {PERIOADA_INALIENABILITATE} ani.
{ENDIF}
```

## Motor de Generare

### Flow Generare Act

1. **Trigger:** Asistent click "Generează Act" pe dosar
2. **Sistem selectează template:** Bazat pe `case.act_type_id` → găsește template activ default
3. **Mapare date:**
   - Părți: Vânzător (prima parte cu rol "Vânzător") → extrage nume, CNP, adresă, CI
   - Cumpărător (prima parte cu rol "Cumpărător")
   - Obiect: Primul imobil din case_objects → extrage adresă, cadastral, suprafață
   - Preț: `case.transaction_value`
4. **Conversie preț în litere:** Algoritm RO-specific (150000 → "o sută cincizeci de mii lei")
5. **Replace variabile în template DOCX:**
   - Open template.docx (XML processing)
   - Find & replace fiecare `{VARIABLE}` cu valoarea reală
6. **Generare output:**
   - DOCX editabil (pentru ajustări manuale de notar/asistent)
   - PDF preview (pentru review rapid)
7. **Salvare:** Document generat → Anexat la dosar, categorie "Generated Acts"

### Engine Options

**Librării:**
- **Python:** `python-docx` pentru manipulare DOCX
- **.NET:** `DocX` sau `Open XML SDK`
- **Node.js:** `docxtemplater`

## Versioning Documente

### Scenario
Client schimbă prețul cu o zi înainte de semnare → Act trebuie regenerat.

### Flow

1. **Generare inițială:** Act V1 (PRET=150000)
2. **Modificare dosar:** Update `case.transaction_value` → 145000
3. **Regenerare:** Click "Regenerează Act"
4. **Sistem:**
   - Salvează V1 cu label "Superseded by V2"
   - Generează V2 (PRET=145000)
   - Marchează V2 ca "Current version"
5. **Vizualizare:** Istoric versiuni pe dosar, cu diff highlighting (ce s-a schimbat)

### Metadata per versiune
- Version number (V1, V2, V3...)
- Generated at (timestamp)
- Generated by (user)
- Changes (optional text: "Modificat preț de la 150k la 145k")

## Clauze Speciale (Roadmap)

### Tipuri

**Clauză de inalienabilitate:**
- Bunul nu poate fi vândut X ani
- Checkbox în dosar: "Include clauză inalienabilitate" → Input: Perioadă (ani)
- Template conține bloc condiționat `{IF...}`

**Clauză de întreținere:**
- Donatarul se obligă să întrețină donatorul
- Specific pentru donații

**Drept de uzufruct:**
- O persoană are nuda proprietate, alta uzufructul
- Detalii: Uzufructuar (nume, CNP), Durată

**Servituți:**
- Drept de trecere, vedere, etc.
- Text liber sau template pre-configurat

### Implementare

**În template:**
```
{IF HAS_USUFRUCT}
Art. X - Drept de uzufruct
Uzufructul bunului revine domnului/doamnei {UZUFRUCTUAR_NUME}, CNP {UZUFRUCTUAR_CNP},
pe o durată de {USUFRUCT_DURATA} ani.
{ENDIF}
```

**În dosar:**
- Tab "Clauze speciale"
- Checkbox-uri pentru fiecare tip
- Form-uri pentru detalii când checkbox bifat

## Minute vs Copii Legalizate

### Context Legal
- **Minut** = Original act, păstrat de notar (arhivă 30 ani)
- **Copie legalizată** = Copie pentru părți

### Implementare

**La generare PDF final (pentru semnare):**
- Watermark: **"MINUT"** (font mare, semitransparent, diagonal)
- Metadata PDF: Title="Minut act nr. {NR_REPERTORIU}/{AN}"

**Generare copii:**
1. Asistent: "Generează copie legalizată" pe dosar semnat
2. Sistem:
   - Ia PDF minut
   - Replace watermark: **"COPIE LEGALIZATĂ DUPĂ MINUTUL NR. {NR_REPERTORIU}/{AN}"**
   - Adaugă număr copie: "Copia nr. 1 eliberată la data {DATA}"
3. Salvare în dosar + înregistrare în CopyIssuance

**Tracking copii:**
- Câte copii au fost eliberate?
- Cui? (client_id)
- Când? (issue_date)
- Cine a eliberat? (user_id)

## Multi-Language Support (Roadmap V2+)

### Context
Acte pentru uz internațional (apostilă) necesită traducere sau generare directă în EN/FR.

### Implementare

**Template multilingv:**
- Template EN: "Sales Agreement" (aceleași variabile, text EN)
- Template FR: "Acte de Vente"

**Selectare limbă:**
- La generare act: Dropdown "Limbă: RO / EN / FR"
- Sistem folosește template corespunzător

**Apostilă:**
- Checkbox pe dosar: "Necesită apostilă"
- Task automat: "Trimite act la Camera Notarilor pentru apostilă"
- Upload confirmare apostilă → Document anexat

## Gestionare Versiuni Template

### Scenario
Legislația se schimbă → Template "Vânzare-Cumpărare" trebuie actualizat.

### Flow

1. **Administrator:** Edit template "Vânzare-Cumpărare v2025" → Upload DOCX nou
2. **Sistem:**
   - Creează versiune nouă: "Vânzare-Cumpărare v2026"
   - Marchează v2025 ca "Active for existing cases" (dosare deja create continuă cu v2025)
   - Marchează v2026 ca "Default for new cases"
3. **Dosare noi:** Folosesc v2026 automat
4. **Dosare vechi:** Continuă cu v2025 (consistency)

### Istoric versiuni
- Administrator vede lista versiuni per template
- Poate reactiva o versiune veche dacă e nevoie

## Validări Pre-Generare

Înainte de generare act, sistem verifică:

**Date obligatorii complete:**
- ✅ Toate părțile au CNP, adresă, CI
- ✅ Obiect (imobil) are adresă, cadastral
- ✅ Preț înregistrat

**Alertă dacă lipsesc:**
- ❌ "Nu se poate genera act: Cumpărător nu are CNP introdus"
- Blocare generare până la completare
